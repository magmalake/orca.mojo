- **The runtime image is distroless:** `morca-runtime` is built on `gcr.io/distroless/cc-debian12` with a static busybox `sh`, util-linux's `setpriv` and an `ldd`, no bash or apt-get, so a project Dockerfile that `RUN`s in a stage `FROM` it must install packages in a build stage and copy them in; deploy it with this release's `morca-stack`, whose health probe uses busybox's `nc`.
