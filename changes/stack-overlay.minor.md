- **A stack's overlay on morca.toml**: a stack's own changes to the project's `morca.toml` (a dev stack's `fills`, a lab stack's pipelines) go in an overlay kept with the stack (`CONFIG_OVERLAY_FILE` in hetzner.env, `MORCA_CONFIG_OVERLAY`, `--overlay`), which deploy.sh sends and the image's morca checks before a deploy changes anything; `enabled = false` keeps a pipeline out of `morca register`, and `morca config show --file` prints the merged file.
